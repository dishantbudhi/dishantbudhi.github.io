# Project images

Place project images in this folder, then set each project's single
`previewImage.src` and its `detailImages` list in
`public/data/projects/index.json`.

Example: `/images/projects/spotify-dashboard.webp`

Images are automatically cropped with `object-fit: cover`. Use the optional
`position` field (for example, `center 30%`) to control the focal point.
