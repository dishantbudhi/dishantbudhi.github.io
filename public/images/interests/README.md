# Interest detail images

Each interest page reads its image paths from `public/data/hobbies/index.json`.

Add square or landscape WebP files under the matching interest folder using these names:

- `detail-03.webp`
- `detail-04.webp`
- `detail-05.webp`

Supported folders are `sports`, `history`, `music`, `film`, `arts`, and `philosophy`. Images are automatically cropped to the gallery frame. Missing files display styled placeholders instead of broken images.
